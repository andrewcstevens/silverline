# Silverline Prohibited Language

## Purpose

Silverline must not use wording that converts historical/proxy/contextual information into implied certainty, financial advice, execution capability, or gambling-style urgency.

## Absolute prohibitions

Do not use the following in product copy, UI, notifications, documentation that reaches users, or promotional concepts:

- Guaranteed
- Guarantee
- Sure thing
- Cannot lose
- Risk-free
- Winning trade
- Winner
- Strong buy
- Buy now
- Take the trade
- Take the window
- Claim the window
- Do not miss
- Last chance
- Urgent
- Lock it in
- Beat the market
- Alpha generator
- Alpha machine
- Oracle
- Truth price
- Market intent
- Market knows
- Hidden liquidity
- Smart-money signal
- Predicted outcome
- Certain outcome
- High-certainty trade
- Execution-ready
- One-click execution
- Automated bet
- Automatic resolution

## Conditional prohibitions

The following are allowed only when technical facts satisfy the claim and CTO has verified the usage:

| Phrase | Condition |
|---|---|
| Live | The underlying source and rendering are technically live/current and freshness is visible |
| Real-time | Data refresh semantics support this exact claim |
| Settlement / settled | Verified settlement data is present; otherwise use historical/replay outcome |
| Price | Source, quote/reference context, and timestamp are visible |
| Kalshi quote | Kalshi is the actual source; show reference status and freshness |
| Expected value / EV | Calculation inputs, assumptions, price/reference, and limitations are available |
| Golden Window | PRE qualifying condition is verified and required qualifier is present |

## Required replacements

| Avoid | Use instead |
|---|---|
| Buy now | Inspect entry |
| Strong buy | Golden Window — review price and evidence |
| Winning trade | Historical/replay outcome or qualifying historical alignment |
| Prediction | Historical read / observed historical rate / assessment |
| Live settlement | Recorded historical outcome, unless verified live settlement exists |
| Signal says Up | Historical evidence favors Up in the displayed sample |
| Best trade | Best currently observed alignment under PRE rules |
| Market price | Kalshi reference quote / displayed contract reference price |
| AI confidence | Evidence range and observation count |
| Alpha | Price-adjusted historical context |

## Source and proxy restrictions

- Never describe Coinbase BTC-USD spot candles as prediction-market settlement data.
- Never describe a proxy input as confirmed contract outcome data.
- Never label a fixture, replay, delayed, stale, or historical value as live/current.
- Never omit source and freshness when a price/quote claim could affect a manual decision.

## Tone restrictions

Avoid casino framing, gamified victory language, urgency, celebration around hypothetical gains, confetti, countdown pressure, streak language, and loss-shaming language.

The preferred posture is: observe, inspect, compare, qualify, and decide manually.
